# Debian/Linux icon installation

Recommended locations:

- Scalable SVG: `~/.local/share/icons/hicolor/scalable/apps/panelide.svg`
- PNG fallbacks: `~/.local/share/icons/hicolor/<SIZE>x<SIZE>/apps/panelide.png`
- Desktop file: `~/.local/share/applications/panelide.desktop`

After installing icons, desktop environments usually refresh automatically. If needed, update the icon cache for the relevant hicolor directory.
